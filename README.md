# Fitrip Fitness Club Website

Ghana's premier fitness community in Dzorwulu, N1 Highway.

## Features
- CrossFit, Boxing, Spinning, Yoga, Bodybuilding & more.
- Responsive design.
- Ghana-themed aesthetics (Red, Gold, Green accents).

## Development

### Local Server
A local server is required to view the website correctly due to file paths and potential future API integrations.

#### Using Python (Simple)
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

#### Using Node.js (Live Reload)
```bash
npm install
npm run dev
```

## Project Structure
- `index.html`: Homepage.
- `aerobics.html`, `boxing-program.html`, etc.: Program and gallery pages.
- `css/`: Modular stylesheets.
- `js/`: Application logic.
- `images/`: Local image assets.
